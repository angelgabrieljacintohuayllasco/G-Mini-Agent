Primera versión con instalador. Cambia casi todo por dentro: el agente ve lo que pasa con sus acciones, recuerda de verdad, habla con más voces y puede quedarse trabajando en un servidor.

## Descargas

| Sistema | Archivo |
|---|---|
| Windows 10 y 11 (64 bits) | `G-Mini-Agent-Setup-0.2.0.exe` |
| Linux (64 bits, beta) | `G-Mini-Agent-0.2.0.AppImage` |

La primera vez que abres la app prepara su propio Python con los componentes del núcleo (unos 500 MB, de 1 a 5 minutos según tu conexión). No toca el Python que ya tengas. El instalador de Windows no está firmado: si SmartScreen avisa, elige "Más información" y luego "Ejecutar de todas formas".

Para un servidor sin escritorio (VPS, Raspberry Pi) no hace falta nada de esto: hay un instalador de una línea en el README.

## Novedades

- **Proveedores**: 30 proveedores con un solo router y fallback que de verdad cambia de proveedor cuando uno falla. Vertex AI con tu sesión de Google Cloud, sin API key. Tu suscripción de Claude o ChatGPT a través de Claude Code y Codex CLI.
- **Memoria**: recuerdos de largo plazo con embeddings, perfil del usuario en cada conversación y modo aprendiz que anota preferencias y lecciones al terminar cada turno, sin duplicados.
- **Identidad**: asistente inicial de siete pasos; el agente usa el nombre y la personalidad que le pongas.
- **Skills**: formato SKILL.md (incluidas, importadas desde GitHub o escritas por el propio agente con tu aprobación) y herramientas ejecutables en sandbox.
- **Conectores**: clima, tipo de cambio del BCRP, feriados, Wikipedia, RSS, lector web, GitHub y PyPI/npm.
- **Voz**: voces neuronales de Edge gratis (por defecto en español de Perú), OpenAI y Gemini 3.8 TTS; conversación en tiempo real con Gemini Live; la app arranca 14 segundos más rápido porque ya no carga modelos de voz al inicio.
- **Chat**: comandos con "/" (`/plan`, `/skill`, `/recuerdos`, `/nombre` y más), comandos propios en Markdown, modo plan y hooks antes y después de cada acción.
- **Servidor 24/7**: modo sin pantalla, API remota v1 con emparejamiento por código, chat por SSE, voz, tareas en segundo plano y WebSocket para dispositivos.
- **Interfaz**: rediseño con temas, acentos y densidad; paleta de comandos, búsqueda, exportar conversaciones, páginas de Memoria y Skills; iconos Lucide.

## Seguridad

- Token de sesión por arranque y validación de Host en el núcleo; WebSockets cerrados a orígenes web ajenos.
- La voz y los sub-agentes pasan por la misma policy de permisos que el chat.
- Sandbox de código que falla cerrado sin Docker, lectura bloqueada de almacenes de credenciales y escritura bloqueada sobre la config, el código y las skills del propio agente.
- API keys en el almacén de credenciales del sistema; en servidores sin uno, en un archivo con permisos 600.

## Arreglos importantes

- El modelo ahora recibe el resultado de sus acciones; antes actuaba a ciegas.
- Detener corta de verdad y los comandos de terminal tienen límite de tiempo.
- MCP: respuestas emparejadas por id y descubrimiento de servidores sin bloquear el arranque.
- Compatibilidad con anthropic 1.x, openai 3.x, google-genai 2.x y Python 3.11 a 3.13.
- Los ajustes nuevos llegan con cada actualización: `config.user.yaml` guarda solo lo que cambiaste.
