G-Mini ahora controla el escritorio con cualquier modelo que vea imágenes, escucha "Oye G-Mini", delega tareas a otro G-Mini y trae una interfaz mucho más completa. Al actualizar, la app completa su entorno sola la primera vez (Whisper y el OCR de Windows).

## Descargas

| Sistema | Archivo |
|---|---|
| Windows 10 y 11 (64 bits) | `G-Mini-Agent-Setup-0.3.0.exe` |
| Linux (64 bits, beta) | `G-Mini-Agent-0.3.0.AppImage` |

El instalador de Windows no está firmado: si SmartScreen avisa, elige "Más información" y luego "Ejecutar de todas formas". Para un servidor sin escritorio está el instalador de una línea del README (con `--voz` para reconocer voz).

## Novedades

- **Control del escritorio con cualquier modelo con visión.** Si el modelo nativo de computer use no está disponible (por ejemplo en Vertex AI), el sub-agente mira capturas con tu modelo de chat y responde acciones; probado con Gemini 3.8 Flash.
- **Ver la pantalla sin instalar nada.** Leer y ubicar texto con el OCR que trae Windows, monitores, y acciones de Android por ADB (teclas, abrir apps, capturas, leer y ubicar texto).
- **Manos libres.** "Oye G-Mini" (o el nombre que le pusiste) abre la conversación por voz y lo que digas después va como primer mensaje.
- **Gemini con tu cuenta de Google.** Proveedor nuevo vía Gemini CLI, junto a Claude Code y Codex.
- **Otros G-Mini.** Empareja este equipo con un G-Mini en un servidor o en otra PC y delégale tareas desde el chat o desde Ajustes > Dispositivos.
- **Interfaz.** La voz del agente suena también en el chat, catálogo de voces con muestra, sugerencias de comandos "/" al escribir, páginas de Conectores y Dispositivos, canvas que se actualiza en vivo y opción "Modelo de chat con capturas" para computer use.
- **Memoria de proyecto.** Si un repositorio tiene GMINI.md, AGENTS.md o CLAUDE.md, el agente los lee antes de editar.
- **Canvas.** El agente arma tableros de estado, métricas, listas y tablas que se actualizan mientras trabaja.

## Arreglos importantes

- Claude Code, Codex y Gemini CLI fallaban siempre al usarse desde el chat.
- El cron de las tareas programadas usaba UTC: "7 de la mañana" corría a las 2 en Perú. Ahora usa tu zona horaria.
- Voz en tiempo real: OpenAI y xAI no conectaban con websockets nuevos; Gemini Live en Vertex reconecta a Vertex, avisa cuando la sesión termina y un doble clic ya no abre dos sesiones.
- La voz simulada ya no acumula silencio ni se cuelga con ruido de fondo.
- Whisper transcribe aunque PyAV sea nuevo.
- Las tareas del servidor que quedaron a medias se retoman tras un reinicio.
- El prompt del agente nombraba unas 30 acciones que no existían; ahora solo nombra las reales.
- Los ajustes nuevos llegan con cada actualización: config.user.yaml guarda solo lo que cambiaste.
- Los errores de proveedor dicen qué falló y qué hacer.
